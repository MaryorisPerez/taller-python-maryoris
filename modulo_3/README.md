# Material complementario — Módulo 3

Plantillas que vas a usar para armar tu repo en GitHub.

## Qué hay adentro

`gitignore_template.txt` tiene el contenido sugerido para tu archivo `.gitignore` (sección 3.8 de la guía). Lo abres, copias todo el contenido y lo pegas en un archivo nuevo que se llame exactamente `.gitignore` — con el punto al inicio, sin extensión. Personalízalo si tu proyecto necesita ignorar archivos adicionales.

`README_template.md` es la plantilla del README para tu repo (sección 3.14). Cópialo a la raíz de tu proyecto, renómbralo a `README.md` y reemplaza `[Tu Nombre]` con tu nombre real. Si la estructura de tu proyecto se ve distinta a la que dice la plantilla, ajústala — el README debe reflejar tu repo, no copiar el mío.

`issue_entrega_template.txt` es el texto del Issue de entrega (sección 3.15). Lo usas solo cuando estés listo para entregar. El archivo te indica dónde crear el Issue y qué pegar como contenido.

## La convención del nombre del repo

El repo se debe llamar exactamente:

```
taller-python-<tu-nombre>
```

Por ejemplo: `taller-python-juan-perez`. En minúsculas, con guiones (no espacios ni guiones bajos), sin tildes ni ñ. Esta convención no es capricho — me permite encontrar a todos los participantes rápido cuando entro a revisar.
